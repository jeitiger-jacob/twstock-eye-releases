# 台股天眼（安裝檔）

這裡只放「台股天眼」的 Windows 安裝檔與自動更新資訊，程式碼不公開。台股天眼是 Jacob 自己做給家人使用的台股參考工具，只提供資料與「值不值得投資」的參考分數，**不會下單、不會連到證券帳戶，也不保證獲利**。

## 第一次安裝

1. 到右邊的 **Releases**，點最新版本，下載 `twstock-eye-setup-版本.exe`。
2. 執行安裝檔。因為程式沒有購買數位簽章，Windows 可能顯示「Windows 已保護您的電腦／未知的發行者」。
   **確認檔案是從這個頁面下載的**，再按「其他資訊」→「仍要執行」。其他來源的檔案不要執行。
3. 第一次開啟會下載近兩年的台股資料，約 1.5～2 小時，請讓程式開著。

## 之後的更新

程式開啟時會自動檢查這裡有沒有新版本。有新版時會跳出視窗說明更新內容：

- 按「現在更新」會在背景下載，下載完會問要不要立刻重新啟動。
- 更新前會自動把資料備份到桌面。資料存在電腦的使用者資料夾，更新不會遺失。
- 更新時 Windows 也可能出現安全提醒，原因同上；只要是台股天眼自己跳出的更新，就可以放心按允許。

有問題請告訴 Jacob。
